# RockPaperScissors

This is the same simple rock paper scissors game to help me compare programming languages and practice writing the same functionality using different languages. 

# Languages 

- Python 
- Java
- C

# Features 

- Player vs Computer
- Random computer choices 
- Score tracking 
- Input validation 
- Multiple rounds 

# Language Comparison 

| Concepts | Python | Java | C |
|---|---|---|---|
| input | input() | Scanner | scanf() |
| output | print() | System.out.println() | printf() |
| random | random.choice() | random.nextint() | rand() % size |
| string | built-in str | String | char */char[] |
| string comparison | ==  | .equals() | strcmp() |
| array/list | list | ArrayList | array [] |
| dictionary/map| dict | HashMap | -- |
| score(data structure)| dictionary | HashMap | struct |
| lowercase | .lower() | .toLowerCase() | tolower() |
| function | def () | method | function |
| validation | try/except | try/catch | return values |
| boolean | True/False | true/false | 1/0 |
| logical AND | and | &&  | && |
| logical OR | or | ||  | || |
| logical NOT | not| ! | ! |
| equal| == | == | == |
| not equal | != | != | != |
| increment | += 1 | ++/+= 1 | ++/+= 1|
| loop | while/for | while/for | while/for |
| conditional | if/elif/else | if/else if/else | if/else if/else |
| no value | None | null | NULL/0 |
| memory/pointers | - | - | */& |
| import | import | import | #include |
| program entry point | - | main() | main() |
